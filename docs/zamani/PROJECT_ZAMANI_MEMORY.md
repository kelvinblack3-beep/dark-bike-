# PROJECT ZAMANI — Canonical Project Memory & Development Rules

This file is the canonical persistent project memory and governance document for Project Zamani. It is authoritative for repository organisation, memory, and project process. Do not perform engineering research in this task; this file is for memory and rules only.

1. PROJECT IDENTITY

Project: PROJECT ZAMANI

Vehicle concept:
Extreme lightweight futuristic single-seat performance/track vehicle.

Styling direction:
A futuristic evolution of the BAC Mono concept, but NOT a copy.
The design objective is a substantially more advanced, distinctive and technologically ambitious vehicle.

Current vehicle target remains provisional:

Mass: approximately 500–700 kg

Architecture status:

UNFROZEN

2. IMPORTANT ARCHITECTURE CORRECTION

The previous 3-cylinder radial motorcycle/engine direction is NO LONGER the active Project Zamani vehicle powertrain baseline.

Do NOT carry the previous 3-cylinder radial-engine architecture into future Zamani research unless explicitly requested.

The current power-system investigation is focused on discovering a physically defensible plasma-related power architecture and determining whether it can ultimately support the vehicle.

3. THREE-DIVISION PROJECT STRUCTURE

DIVISION I
PLASMA POWER SYSTEM RESEARCH

Purpose:
Investigate plasma-related power-generation and energy-conversion architectures.

Current status:
UNFROZEN.

No plasma architecture has yet passed all breakthrough gates.

Previously investigated candidates include:

- microwave plasma propulsion
- plasma-heated Brayton
- direct plasma thermoelectric/Nernst conversion
- liquid-metal MHD + plasma
- plasma-assisted combustion
- plasma hydrogen reforming
- electrostatic/Post conversion
- tandem-mirror plasma concepts
- TELEC
- plasma-assisted combustion + waste-heat recovery

These results must be preserved but must NOT be treated as the final answer.

The research must remain open to new architectures.

DIVISION II
FUTURISTIC VEHICLE ARCHITECTURE

Purpose:
Develop the physical vehicle architecture independently of the final powertrain.

Current concept:

Single-seat futuristic track/performance vehicle.

Design direction:

"Better than BAC Mono" is the conceptual benchmark, not a requirement to copy its geometry.

Important design characteristics:

- central driving position
- lightweight composite monocoque
- extreme power-to-weight ratio
- advanced aerodynamic platform
- pushrod suspension
- minimal cockpit
- low center of gravity
- aggressive futuristic bodywork
- modular powertrain packaging

Current architecture remains UNFROZEN.

DIVISION III
ADVERSARIAL INDEPENDENT VERIFICATION

Purpose:

Attack every major claim produced by Divisions I and II.

Division III must:

- independently recalculate claims
- identify hidden assumptions
- test energy balance
- test mass balance
- test thermal balance
- test materials feasibility
- test structural feasibility
- test manufacturability
- preserve failures
- prevent premature architecture freezing

Physics is the authority.

6. BREAKTHROUGH DEFINITION

Never label a system "breakthrough" merely because it:

- sounds novel
- has impressive theoretical efficiency
- has a laboratory demonstration
- produces a large number in simulation
- has low theoretical mass

A BREAKTHROUGH CANDIDATE must pass:

1. First-principles consistency
2. Closed energy balance
3. Independent calculation
4. Credible experimental evidence
5. Engineering feasibility
6. Materials feasibility
7. Thermal closure
8. Mass closure
9. Power-density requirement
10. Manufacturability
11. Adversarial verification

Until these gates are passed:

Status = BREAKTHROUGH CANDIDATE

NOT VERIFIED.
